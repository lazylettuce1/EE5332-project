## Floating Point vs Fixed Point
1. Floating is generally preffered since it's easy to work with,
	a wide dynamic range, useful when the output range is unknown.
	quick prototyping
2. Why is it not preffered?
	Very expensive,
	Need to align exponents, normalize results, round results,
	handle special cases such as NaN and infinity, overflow.
3. E2M1 is an example of a floating point variant specifically useful for ML applications due to their high dynamic range, but low precision requirements.
4. `result = (acc + (1 << n-1)) >> n` implements rounding off before truncating for multiplication.
